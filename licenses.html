The Solo Satoshi Web Flasher is free software licensed under GNU GPL version 3 only. Read the full license or download the complete corresponding source for the version currently deployed.

Development history, infrastructure, and business operations are maintained separately from the distributed application. The source archive includes the preferred source form and build files needed for the browser application.

Firmware

The application mirrors unmodified, checksum-verified firmware from bitaxeorg/ESP-Miner and shufps/ESP-Miner-NerdQAxePlus. Both are licensed under GPL version 3. The flasher provides a corresponding tagged source archive beside each firmware release.
