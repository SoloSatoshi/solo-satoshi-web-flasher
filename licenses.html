Firmware

The application mirrors unmodified, checksum-verified firmware from bitaxeorg/ESP-Miner and shufps/ESP-Miner-NerdQAxePlus. Both are licensed under GPL version 3. The flasher provides a corresponding tagged source archive beside each firmware release.

Reference projects

Portions of the flashing workflow, hardware-selection approach, and initial language catalog were adapted from bitaxeorg/bitaxe-web-flasher and shufps/nerdqaxe-web-flasher, both licensed under GPL version 3. Copyright in those upstream works remains with their respective authors and contributors.

The K230 WebUSB transport and KDIMG parser interoperate with the public protocol implemented by kendryte/k230_flash_py, licensed under the MIT License by Canaan INC. The browser fetches the SPI NAND loader from a pinned commit in that official repository and verifies a fixed SHA-256 digest before running it. The loader binary is not distributed by this site.

The optional Nano 3S image is selected by the user and may be built by the community nano-mujina project. No Mujina firmware image is distributed by this site. The official project is 256foundation/mujina.
